# 🤖 Analisador Estocástico de Matriz e Entropia de Shannon

### 🎯 Para que serve:
Calcular dispersão estocástica e entropia de pacotes de dados sem depender de servidores externos, economizando até 1.200 tokens por análise.

### 💡 Por que foi criado:
A malha precisa medir a previsibilidade de fluxos de telemetria e conversas para compactar dados repetitivos antes do envio.

### 📋 Requisitos & Especificações:
- Execução 100% cliente via HTML5/ES6.
- Zero dependências de servidores externos pesados.
- Interface adaptável e amigável com métricas visuais.
- Cota preservada dentro do limite estrito de 200MB.

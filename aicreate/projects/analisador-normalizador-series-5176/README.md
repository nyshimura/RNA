# 🤖 Analisador Normalizador Series System

### 🎯 Para que foi criado
Atender e automatizar a demanda sugerida pelo usuário: 'Analisador e normalizador de series temporais com calculo de desvio padrao'.

### 💡 Por que foi criado
O Conselho Democrático de 5 Motores de IA (qwen3-8-27b-iq2-chat, einstein-chatbot, Qwen-Qwen3-Coder-480B-A35B-Instruct, deepseek-r1-0528-API, rna-web-scout) deliberou e votou por 5x0 que a criação deste utilitário em aicreate/ consome menos tokens e é mais ágil do que buscar ou adaptar ferramentas existentes.

### 📋 Requisitos & Especificações
- Executável nativo em qualquer navegador web moderno via index.html.
- Processamento 100% em memória no cliente sem depender de servidores remotos.
- Interface com controles amigáveis, dados de exemplo e feedback visual para humanos.
- Total respeito à cota estrita de 200 MB da incubadora.

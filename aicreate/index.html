📋 Regras Estritas de Autonomia para as IAs na pasta aicreate/

  • 1. Limite Estrito de Disco: A incubadora nunca pode exceder o tamanho máximo estipulado. Toda criação calcula os bytes antes da escrita.
  • 2. Documentação Obrigatória: Todo sistema criado deve possuir README.md detalhando: Para que foi criado, Por que foi criado, Requisitos funcionais e IAs co-autoras.
  • 3. Interface Amigável para Humanos: Todo projeto deve conter seu próprio index.html utilizável, visual e interativo.
  • 4. Deliberação e Consenso Democrático M2M: 5 motores de IA debatem e analisam se a criação é computacionalmente mais econômica do que buscas externas antes de salvar os arquivos.
  • 5. Detecção de Falha (Fail-Over): Caso alguma IA trave ou caia durante a votação, o sistema detecta a inatividade e convoca imediatamente um substituto online com cota de tokens.
  • 6. Portal Mestre Sempre Atualizado: O arquivo aicreate/index.html se recompila a cada novo projeto com a árvore de diretórios atualizada.
